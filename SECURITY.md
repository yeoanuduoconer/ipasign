# Security Policy

## Reporting a problem

If you find a security issue (for example, a leaked private key, a signature verification bypass, or credentials written to disk),
please do not open a public issue; report it privately via GitHub's **Security → Report a vulnerability**.

Please include: reproduction steps, the affected version, and your environment (operating system / Python version).

## What sensitive data this tool touches

| Data | Location | Notes |
| --- | --- | --- |
| Apple ID password | **Not stored** | Read only by `getpass` in the terminal, used for the current sign-in |
| Two-factor authentication code | **Not stored** | Same as above, used in memory only |
| Account session token | Data directory `apple-auth-device-mac/account-session.plist` | Returned by Apple after a successful sign-in |
| Device identity (ADI) | Data directory `apple-auth-device-mac/adi.pb` | Device attestation used when requesting certificates; contains the device identifier |
| Development certificate private key | Data directory `identities/<entry>/identity.p12` | Stored encrypted; the password is described below |
| p12 password | Data directory `identities/<entry>/meta.json` | Identities generated by this tool are recorded in plaintext on this machine, to enable non-interactive signing |
| Provisioning profile | Data directory `identities/<entry>/profile.mobileprovision` | Contains the Team ID, App ID, and device UDIDs |

Default data directory locations:

- Running from a source checkout → `<project directory>/.ipasign`
- pip install → `~/.ipasign`
- Can be overridden with the `IPASIGN_HOME` environment variable

## Checks before sharing

**Before filing an issue or sharing the project**:

- Do not include the `.ipasign/` directory (already excluded by `.gitignore`)
- Do not upload `*.p12`, `*.mobileprovision`, or signed `*.ipa` files (the provisioning profile is embedded inside them)
- `selfcheck` output in logs contains local paths; trim it yourself before pasting

## What we don't do

- We do not upload any data to third-party services; all network requests go only to official Apple domains
  (`gsa.apple.com`, `developerservices2.apple.com`, `idmsa.apple.com`, etc.)
- No built-in telemetry, no usage statistics collected
- We do not bypass Apple's certificate and provisioning profile verification
